# Bubbistix ✨

**Berry glad you're here 🍓**

Bubbistix is a digital sticker shop website filled with cute digital stickers ready to brighten your day!

---

## 🍓 Features

### 🛍️ Browse Stickers
Users can browse a collection of digital stickers displayed in a gallery-style shop interface.

### 🛒 Shopping Cart
Users can add stickers to a cart before completing their purchase.

### ⭐ Limited Edition Sticker
Bubbistix includes a special limited-edition sticker feature:

- Only one user can claim the sticker
- Once the sticker is claimed, it becomes unavailable for other users
- The availability is controlled through backend logic and stored in the database.

### 💌 Contact / Custom Sticker Requests
Users can send a message through the website to:
- Request custom sticker designs
- Ask questions or provide feedback
- Send general inquiries to the Bubbistix team
